To quantify uncertainty in generic Chave AGB estimates, a 1,000-draw Monte Carlo simulation per tree was implemented (every stem of all 21 trees perturbed independently; fixed random seed). Uncertainty distributions were specified based on field measurement precision: DBH: Normal distribution N(DBH, σ = 0.3 cm) reflecting tape alignment error; Height (H): Normal distribution N(H, σ = 0.8 m) accounting for optical clinometer visual obstruction; Wood Density (ρ): Uniform distribution U(0.9ρ, 1.1ρ), i.e. ±10% around the species value in the group sheet, as the sheet holds a single ρ per species [2].
